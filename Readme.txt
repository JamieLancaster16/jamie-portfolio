JAMIE LANCASTER PORTFOLIO - GITHUB / CLOUDFLARE PACKAGE
=========================================================

This redesign takes inspiration from the overall structure of the uploaded SnapFolio template:
- fixed side navigation
- large hero
- about / skills / experience / portfolio / capability sections
- separate detail pages

The content and visual design in this package have been rewritten for Jamie Lancaster.

BEFORE PUBLISHING
-----------------
1. Replace YOUR-EMAIL-HERE
2. Replace YOUR-LINKEDIN-HERE
3. Add your real profile image as:
   assets/img/profile/jamie-profile.jpg

4. In index.html replace the profile placeholder block with:
   <img src="assets/img/profile/jamie-profile.jpg" alt="Jamie Lancaster">

5. Add portfolio images under:
   assets/img/portfolio/

6. Replace the placeholder blocks in portfolio-details.html with real screenshots/photos.

7. Add your CV PDF if required.

GITHUB
------
Upload the CONTENTS of this folder to the repository root so index.html is at the top level.

CLOUDFLARE PAGES
----------------
Connect the GitHub repository.
Production branch: main
No build step is required.
The site is plain HTML/CSS/JavaScript.

GITHUB PAGES
------------
This package uses relative paths, so it also works from a GitHub Pages project subfolder.

PORTFOLIO PRIVACY
-----------------
Do not publish:
- student information
- private staff information
- internal audit findings
- confidential regulatory correspondence
- passwords or system details
- assessment answers or benchmarks that compromise assessment integrity
- internal documents you do not have permission to share
