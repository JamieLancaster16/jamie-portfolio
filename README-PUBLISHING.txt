JAMIE LANCASTER PORTFOLIO SITE

This is a multi-page static website.

Before publishing:
- Replace YOUR-EMAIL-HERE and YOUR-LINKEDIN-HERE
- Add your final CV as assets/documents/Jamie-Lancaster-CV.pdf
- Add images into the matching assets/images folders
- Replace placeholder blocks in case-study pages with <img> tags
- Redact student data, internal audit findings, assessment answers, confidential correspondence and information you do not have permission to share

Example image code:
<img src="/assets/images/training/01-workshop.jpg" alt="First Aid workshop activity">

NETLIFY
1. Unzip this package.
2. Drag the whole jamie_portfolio_site folder into Netlify Drop.
3. Netlify gives you a public URL.
4. Add a custom domain later if desired.

CLOUDFLARE/GITHUB
Upload the folder to a GitHub repository and connect the repository to Cloudflare Pages or GitHub Pages.
